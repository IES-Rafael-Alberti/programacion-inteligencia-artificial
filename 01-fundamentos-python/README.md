# 01 - Fundamentos de Python

## Propósito

Unidad introductoria que cubre los fundamentos de programación en Python orientados al análisis de datos e IA. Trabaja los RA/CE iniciales del módulo: sintaxis básica, estructuras de datos, control de flujo, funciones, orientación a objetos y computación numérica con NumPy/JAX. Incluye también una introducción a R como lenguaje complementario.

## Materiales incluidos

- **Teoría (01-teoria/):** Índice de cobertura, guía de unidad, guías de Python, orientación a objetos y documentación de apoyo. Los conceptos básicos se trabajan como teoría guiada en los notebooks de `02-ejemplos/`.
- **Ejemplos (02-ejemplos/):** Notebooks demo de introducción a Python, variables, control de flujo, estructuras de datos, orientación a objetos (`05_orientacion_objetos_python.ipynb`), NumPy, broadcasting, JAX y R.
- **Prácticas (03-practicas/):** Notebooks de repaso, estructuras de datos, ejercicios de POO (`06-ejercicios_poo.ipynb`), EDA y NumPy con tests.
- **Evaluación (04-evaluacion/):** Rúbrica, checklist, cuestionario base y actividad breve de comparativa de lenguajes/formatos para IA.
- **Recursos (05-recursos/):** Chuletas de Python básico, estructuras de datos y NumPy. Entorno conda (`pia-ud1.yml`).
- **Archivo (90-archivo/):** ZIP con tutoriales externos de NumPy.

## Prácticas asociadas

- Ejercicios de Python básico (bloques iniciales): sintaxis, variables, control de flujo, funciones, estructuras de datos
- Guía de orientación a objetos: clases, composición, herencia y protocolos de objetos, como preparación para PyTorch
- Notebook guiado y ejercicios de orientación a objetos (`02-ejemplos/05_orientacion_objetos_python.ipynb`, `03-practicas/06-ejercicios_poo.ipynb`)
- Actividades NumPy: ejercicios guiados de computación numérica
- Ejercicios NumPy con tests automatizados
- Comparativa breve de lenguajes y formatos para IA (`04-evaluacion/comparativa-lenguajes-formatos-ia.md`)
