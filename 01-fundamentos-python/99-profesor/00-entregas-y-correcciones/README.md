# Entregas y correcciones — material interno del profesorado

> **Documento y carpeta internos. Solo repositorio docente; no publicar en `main` del alumnado, GitHub Pages ni Moodle.** Esta ruta vive bajo `99-profesor/` y está ignorada por Git del repositorio público, por lo que no se incluye en ninguna publicación.

Esta carpeta guarda las **entregas del alumnado y su corrección** (evidencia de trabajo), separadas de los **instrumentos de evaluación** de `04-evaluacion/` (cuestionarios GIFT, rúbricas, checklist, comparativa).

## Estructura propuesta

- Una subcarpeta por actividad/entrega, p. ej.:
  - `UD1-comparativa/`: entregas de la comparativa de lenguajes y formatos.
  - `UD1-ejercicios-numpy/`: entregas de los ejercicios/EDA de NumPy.
  - `UD2-.../`: según las unidades que se vayan corrigiendo.
- Dentro de cada subcarpeta, las entregas de cada alumno y, cuando proceda, un `registro-correccion.md` o la hoja de calificación por RA/CE.

Esta carpeta no forma parte de la evaluación pública: Moodle organiza los instrumentos y el tiempo de clase; la corrección de entregas es trabajo interno del profesorado.

## Convenio

- Los instrumentos evaluables (enunciados, rúbricas, GIFT) permanecen en `04-evaluacion/` de cada unidad.
- Las soluciones de referencia, cuando existan, van en `99-profesor/03-practicas-soluciones/` o aquí si acompañan a una entrega concreta.
- La calificación oficial se calcula por RA/CE en Séneca; esta carpeta solo conserva las evidencias.
