## Resumen de qué se evalúa

| Dimensión | Evidencia esperada |
| --- | --- |
| Tema y viabilidad | Propuesta validada con al menos dos fuentes de datos diferenciadas. |
| Checkpoints progresivos | Entregas parciales según el calendario indicado en `checkpoints_proyecto_final.md`. |
| Integración de fuentes | Fusión real entre fuentes, no unión superficial. |
| Componente IA/ML | Modelo o sistema justificado y evaluado con métricas. |
| Salida útil | API, dashboard, informe, asistente u otra interfaz razonada y funcional. |
| Documentación y defensa | Documentación técnica suficiente y presentación o defensa final. |

## Criterios de superación

- El proyecto supera cada checkpoint con el visto bueno del profesorado.
- La solución final integra al menos dos fuentes de datos y un componente de IA/ML.
- La entrega permite reproducir o revisar la solución sin pasos ocultos.
- No se publican claves, tokens ni datos sensibles en la entrega.
