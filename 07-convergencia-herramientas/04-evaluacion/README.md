# Evaluación — UD7 Convergencia de Herramientas IA

Esta carpeta reúne los instrumentos de evaluación de la unidad, que está completada y verificada.

## Instrumentos disponibles

| Fichero | Qué evalúa |
| --- | --- |
| `rubrica_proyecto.md` | Rúbrica del proyecto integrador (pipeline completo: datos, experimentación, serving, agentes, observabilidad). |
| `criterios_evaluacion.md` | Criterios generales de evaluación de la unidad y descripción de evidencias esperadas. |
| `examen_teorico.gift` | Cuestionario GIFT de comprensión teórica sobre el stack convergente (Prefect, MLflow, LlamaIndex, CrewAI, Evidently, etc.). |

## Prácticas evaluables

Las prácticas P1–P8 (`03-practicas/`) constituyen el recorrido del pipeline completo. El proyecto integrador final evalúa la capacidad de conectar todas las piezas en un flujo coherente.

Para el detalle de criterios por práctica y la ponderación, consultar `criterios_evaluacion.md` y `rubrica_proyecto.md`.

## Criterios de superación

- El proyecto integrador ejecuta el flujo principal de extremo a extremo.
- Las evidencias permiten verificar cada fase del pipeline sin adivinar pasos.
- La documentación técnica es suficiente para reproducir la solución.
