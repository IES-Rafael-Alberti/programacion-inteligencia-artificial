# Checklist de publicacion Moodle - arranque y UD1 - PIA 2026/2027

Objetivo: dejar Moodle listo antes de la primera clase sin abrir todavia tareas
evaluables ni fijar plazos innecesarios.

Los archivos preparados para subir estan reunidos en `Moodle/00-inicio-ud1/`.
Consultar `Moodle/00-inicio-ud1/README.md` para la relacion entre cada archivo,
el recurso Moodle y su fuente.

## Seccion UD1 - Fundamentos de Python

### Publicar antes o durante la primera clase

- [ ] Crear la seccion `UD1 - Fundamentos de Python`.
- [ ] Publicar la guia de unidad:
  `01-fundamentos-python/01-teoria/00-guia-unidad.md`.
- [ ] Publicar el primer bloque:
  `01-fundamentos-python/01-teoria/01-guia-python-basico.md`.
- [ ] Publicar el notebook de inicio:
  `01-fundamentos-python/02-ejemplos/01_introduccion_entorno_python.ipynb`.
- [ ] Publicar la practica de repaso como recurso sin calificacion:
  `01-fundamentos-python/03-practicas/05_repaso_y_ejercicios_basicos.ipynb`.
- [ ] Publicar las chuletas `00_ChuletaPythonBasico.md` y
  `00_ChuletaLsts_Tupls_Diccs_Sets.md` de `01-fundamentos-python/05-recursos/`.
- [ ] Indicar Pixi `default` para JupyterLab y Google Colab como alternativa
  temporal si un equipo no puede preparar Pixi.

### Preparar sin publicar como evaluable

- [ ] Crear la categoria `UD1 - Fundamentos Python` con media ponderada.
- [ ] Crear la subcategoria `UD1 - Cuestionarios Moodle`.
- [ ] Importar y previsualizar `04-evaluacion/cuestionario-base.gift`. No abrir
  el cuestionario hasta comprobar preguntas y retroalimentacion.
- [ ] Crear borradores de `ud1-practica-python` y
  `ud1-comparativa-lenguajes`, sin fecha ni visibilidad para alumnado.
- [ ] Aplicar los pesos al activar los instrumentos: practica Python y NumPy 60 %,
  comparativa de lenguajes 20 % y cuestionarios 20 %.

## Comprobacion con cuenta de prueba

- [ ] La cuenta ve las secciones inicial y UD1 sin permisos de edicion.
- [ ] Todos los enlaces abren el recurso correcto.
- [ ] El notebook se descarga o abre correctamente.
- [ ] No se publica ninguna solucion ni material de `99-profesor/`.
- [ ] Los items de calificacion no duplican tareas o cuestionarios.
- [ ] El total Moodle se identifica como informativo; Seneca mantiene la nota
  oficial por RA/CE.

## Despues de la primera clase

1. Anotar y resolver las incidencias reales de acceso o entorno.
2. Publicar el siguiente notebook cuando el grupo haya completado el inicio.
3. Abrir el primer instrumento evaluable solo con enunciado, rubrica, plazo y
   enlace a las normas comunes.
