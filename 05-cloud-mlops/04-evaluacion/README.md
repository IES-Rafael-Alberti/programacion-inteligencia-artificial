# Evaluación — UD5 Cloud y MLOps

Esta carpeta reúne los instrumentos de evaluación de la unidad: cuestionarios GIFT de comprensión teórica sobre infraestructura cloud, MLOps, IA generativa y RAG.

## Camino rápido

1. Completa la tarea comparativa de herramientas cloud o la tarea AWS según indique el profesorado.
2. Entrega el trabajo con justificaciones técnicas claras.
3. Realiza los cuestionarios GIFT si el profesorado los activa en Moodle.

## Instrumentos disponibles

| Fichero | Qué evalúa |
| --- | --- |
| `cuestionario_1_infraestructura_datos.gift` | Infraestructura cloud para datos: feature stores, almacenamiento, compute, orquestación. |
| `cuestionario_2_ia_generativa_rag.gift` | IA generativa, RAG, APIs LLM, serving y stacks de IA en cloud. |

## Prácticas evaluables

| Práctica | Descripción |
| --- | --- |
| Tarea comparativa de herramientas cloud | Análisis y justificación de selección de herramientas cloud para un caso de uso. Enunciado y rúbrica en `03-practicas/`. |
| Tarea AWS | Implementación básica de infraestructura AWS para un pipeline ML. Rescatada del curso 24-25; enunciado en `03-practicas/`. |

Los cuestionarios GIFT evalúan comprensión conceptual y son complemento de las prácticas, no sustituto salvo decisión expresa del profesorado.

## Criterios de superación

- La tarea entregada justifica las decisiones técnicas con criterio.
- Los cuestionarios se realizan sobre los conceptos trabajados en teoría y ejemplos.
- La entrega no incluye claves, tokens ni credenciales reales.
