# 05-cloud-mlops

## Propósito
Cubre conceptos de cloud computing, MLOps, feature stores, infraestructura cloud para IA, despliegue de modelos, RAG en cloud, y herramientas de orquestación.

## Ruta canónica del alumnado

| Paso | Material |
|---|---|
| Empieza aquí | `01-teoria/01-feature-store.md` y las guías de la categoría asignada en `01-teoria/`. |
| Tarea canónica | [`03-practicas/tarea-comparativa-herramientas.md`](03-practicas/tarea-comparativa-herramientas.md). La tarea AWS heredada queda como alternativa opcional solo si el profesorado la activa. |
| Entrega y evaluación | Un documento individual por categoría y un documento grupal consolidado, valorados con [`03-practicas/rubrica-tarea.md`](03-practicas/rubrica-tarea.md) y [`04-evaluacion/checklist-entrega.md`](04-evaluacion/checklist-entrega.md). |
| Entorno real | La comparativa no requiere instalar un entorno de ejecución: se apoya en las guías de `01-teoria/`, el ejemplo de `02-ejemplos/ejemplo-comparativa.md` y documentación oficial actual de las herramientas. |

## Materiales incluidos
- **01-teoria**: Documentación completa (14 guías en MD+HTML) sobre feature stores, cloud compute, MLOps, almacenamiento IA, frameworks ML, APIs LLM, orquestación, herramientas datos, vectores, serving, RAG, stacks IA
- **02-ejemplos**: Demos de RAG (sencillo, Ollama, PageIndex), pipelines de feature/training/inference con Hopsworks
- **03-practicas**: Tarea comparativa de herramientas cloud + rúbrica. Rescatado de 24-25: scriptAWS.sh, esqueletoAWS.py, tarea AWS (org+pdf)
- **04-evaluacion**: Cuestionarios GIFT (infraestructura datos, IA generativa RAG)
- **05-recursos**: predict_example.py, quickstart_fraud_model, indexed_docs.json
- **99-profesor**: modelos-gpt-5.4.md

## Prácticas asociadas
- **Canónica:** tarea comparativa de herramientas cloud.
- **Opcional:** tarea AWS rescatada del curso 24-25; no forma parte de la ruta ordinaria salvo indicación expresa.

## Opciones docentes

- Activar la tarea AWS únicamente si se dispone de acceso y configuración adecuados; su material no sustituye la comparativa canónica.
