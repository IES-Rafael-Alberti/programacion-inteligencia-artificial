# UD12 — Proyecto Integrado

Usa esta página para localizar el material de la unidad. Los notebooks, datos y otros archivos ejecutables se abren desde una copia local del repositorio.

## Antes de empezar

1. Sigue la [ruta común para trabajar con los materiales](../guia-inicio.md).
2. Consulta el [README de la unidad](../12-proyecto-integrado/README.md) para conocer su alcance.
3. Usa el entorno y el comando indicados en la actividad; no presupongas que existe un entorno único para todo el curso.
