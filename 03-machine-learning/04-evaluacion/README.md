# Evaluación — UD3 Machine Learning

Esta carpeta reúne los instrumentos de evaluación de la unidad: cuestionario GIFT de comprensión teórica y rúbricas para las prácticas de laboratorio y el capstone.

## Camino rápido

1. Completa las prácticas indicadas por el profesorado (Lab1, Lab2, Lab3 o Midterm Capstone).
2. Revisa la rúbrica correspondiente antes de entregar.
3. Realiza el cuestionario GIFT si el profesorado lo activa en Moodle.

## Instrumentos disponibles

| Fichero | Qué evalúa |
| --- | --- |
| `Cuestionario-Bank-Marketing.gift` | Comprensión teórica: tarea Bank Marketing, clasificación, métricas. |
| `rubrica_datasets_peliculas.md` | Labs de creación de dataset (Lab1 TheMovieDB, Lab2 OpenMeteo/AEMET, Lab3 dataset propio). |
| `RubricaPeliculas.md` | Rúbrica del Midterm Capstone (EDA + PyCaret + modelo final de películas). |
| `06-Rubrica_Peliculas.md` | Versión de referencia anterior de la rúbrica de películas (conservar como histórico). |

## Criterios de superación

- La entrega alcanza la puntuación mínima establecida en la rúbrica correspondiente.
- El notebook o informe ejecuta o puede revisarse con las evidencias aportadas.
- Los datos usados y su fuente están documentados.
