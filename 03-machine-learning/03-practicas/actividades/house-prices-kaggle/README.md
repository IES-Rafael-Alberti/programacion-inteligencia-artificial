# House Prices Kaggle — EDA, pipelines y ML tabular

Actividad situada en UD3 porque trabaja análisis exploratorio, preprocesado y modelos clásicos de machine learning sobre un problema tabular de regresión.

## Material activo

- `notebooks/house_prices_advanced_regression2.ipynb`: notebook principal de EDA, preparación de datos y enfoque de pipelines/modelos clásicos.
- `docs/rubrica.md`: rúbrica original de selección, entrenamiento y evaluación de modelos; pendiente de normalización si se convierte en actividad evaluable activa.
- `docs/conceptos.org`: apuntes fuente en Org sobre estadística y transformaciones. Se conserva como material fuente/histórico.

## Datos

Los datos de Kaggle pueden estar disponibles localmente en `data/`, pero no se versionan por la política general de datos. El profesorado indicará en Moodle o en la actividad cómo obtenerlos.
