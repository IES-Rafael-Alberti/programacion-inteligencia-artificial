# AutoML con PyCaret — Used Cars

Actividad situada en UD3 porque trabaja AutoML sobre un problema tabular de regresión, no deep learning como contenido principal.

## Notebook

- `notebooks/vehiculoPycaret.ipynb`: preparación de datos de vehículos usados y uso de PyCaret para regresión del precio.

## Nota

Las trazas locales de MLflow/PyCaret (`mlruns/`) son salida de ejecución y no forman parte del material fuente que debe versionarse.
