# Evaluación base — UD2 Tratamiento de datos

## Propósito

Base revisable para evaluar práctica, notebook y entrega de la unidad. No sustituye la evaluación final de la programación didáctica.

## Instrumentos

- **Práctica/notebook:** análisis y tratamiento de datos con pandas.
- **Entrega breve:** explicación del proceso, decisiones y resultados.
- **Cuestionario Moodle:** apoyo de verificación conceptual.
- **Rúbrica base:** criterio común para corrección inicial.

## Uso en Moodle

- Importar `cuestionario-base.gift` como banco de preguntas o cuestionario.
- Comprobar compatibilidad de importación y símbolos antes de publicar.
- Ajustar puntuación, retroalimentación y pesos según la tarea.

## Itinerario opcional R

Si se activa `../03-practicas/r_exercises_titanic_with_tests/`, se evalúa con la misma lógica conceptual que Pandas: comprensión del dataset, limpieza, transformación, EDA, visualización y reproducibilidad.
