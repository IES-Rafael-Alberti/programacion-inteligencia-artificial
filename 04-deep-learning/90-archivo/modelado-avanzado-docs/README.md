# Archivo de `modelado-avanzado-docs`

Este directorio conserva el residuo histórico retirado del flujo activo de UD4 el 2026-07-05.

## Criterio aplicado

UD4 queda como Deep Learning base. El material residual se conserva aquí cuando es fuente antigua, apoyo duplicado, guía no específica de UD4 o paquete comprimido que no debe vivir en la teoría activa.

| Carpeta | Contenido | Decisión |
|---|---|---|
| `fundamentos/` | Apuntes largos sobre gradiente, backpropagation y teoría general de deep learning. | Archivado: duplica o solapa capítulos activos de fundamentos. |
| `generados/` | PDF derivado de gradiente/backpropagation. | Archivado: no se mantiene en teoría activa. |
| `fuentes-org-tex/` | Fuentes `.org` y `.tex` antiguas. | Conservadas como histórico/fuente, no como flujo activo. |
| `redes-recurrentes/` | Desarrollo largo de RNN/LSTM. | Archivado; UD4 conserva sólo una introducción conceptual y deriva la aplicación a UD6/UD10. |
| `guias-proyecto-ml/` | Guía general de proyecto Python/ML. | Archivada: no es específica de UD4 base; no se mueve a UD3 en esta pasada. |
| `boston-housing/` | Nota textual histórica sobre exploración de datos. | Archivada sin tocar la práctica activa. |
| `conceptos/` | Nota mixta sobre transfer learning y RAG. | Archivada: mezcla visión/LLM y no debe ampliar UD4. |
| `notas-internas/` | Nota de planificación PyTorch. | Conservada como nota interna histórica, fuera del flujo activo. |
| `tareas/` | ZIP de regularización. | Conservado como paquete histórico; no se descomprime en el flujo activo. |

No reactivar este material por inercia: si algo vuelve a clase, debe pasar antes por revisión docente y enlazarse desde la estructura activa.
